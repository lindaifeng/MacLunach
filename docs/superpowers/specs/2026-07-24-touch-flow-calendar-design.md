# 一念流程隐患与日历体验修复设计

**日期：** 2026-07-24

## 目标

修复已确认的高优先级用户流程隐患，确保失败、失焦、停用和权限不足状态都可理解、可恢复；同时将节假日日历改为接近 macOS 日历的连续纵向月份浏览，并强化节日识别。

## 设计范围

### 1. Finder 中继请求安全性

请求信封增加 `createdAt`、`expiresAt` 和 `requestID`。Finder 扩展超时或取消时写入失败终态或原子删除请求；主应用读取请求后先校验版本、过期时间和已处理幂等键，再调用文件服务。响应写入后由消费方删除，异常请求不会在应用重启后被补执行。

### 2. 功能窗口生命周期

功能区窗口统一由宿主协调显示、失焦隐藏、原生关闭和启动器恢复。失焦隐藏不再假设会触发 `windowWillClose`；隐藏和真正关闭都显式通知协调器。所有普通功能窗口使用同一交互窗口层级，移除番茄钟永久压前的行为。

### 3. 设置、权限与错误反馈

设置页移除无动作的“检查更新”和“清理搜索索引”假功能，改为真实的异步状态、结果提示和重试入口。权限中心以统一状态模型展示屏幕录制、日历、通知、文件/Finder 集成等能力，区分未请求、需启用、已授权、被拒绝、受限和通信异常，并提供对应恢复操作。

### 4. 搜索与功能区一致性

应用/文件/动作模式各自保存查询文本，Tab 切换不丢输入。停用插件不出现在启动器卡片、动作搜索和快捷键分配中；设置页仍能重新启用。执行已停用功能时返回明确的可恢复结果。

### 5. 连续月份日历

日历主体使用单列纵向滚动的月份列表，默认定位当前月份，月份标题随滚动更新；每月保留周一至周日网格和农历信息。点击日期打开详情，不改变滚动位置；“今天”滚动回当前月份并选中当天。法定节假日使用高对比主色带，调休上班使用警示色，国际节日使用辅助色，并在月份标题下给出当月节日摘要。

### 6. 节日数据策略

节日数据从“仅 2026 年完整、其他年份三项兜底”改为可扩展的按年表。至少覆盖 2026、2027 年的主要中国法定节假日和调休；没有官方数据的年份显示基础节日并明确不承诺调休，避免静默误导。

## 非目标

- 本轮不重写整个插件注册架构，不迁移所有宿主窗口到动态工厂。
- 本轮不实现滚动长截图、GIF 录制等独立阶段能力。
- 当前环境不承诺真实 Finder、系统权限、XPC、VoiceOver 和多屏行为已完成实机验收。

## 验收标准

- 过期或取消的 Finder 请求不会在下次启动后执行。
- 任意功能窗口失焦后重新回到“一念”仍可通过启动器恢复；原生关闭也能恢复启动器。
- 普通功能窗口点击顺序符合“当前点击窗口在前”，番茄钟不永久遮挡启动器。
- 设置页所有可点击控件都有状态变化或明确不可用说明。
- 搜索模式切换保留各自输入；停用插件不会出现在用户可执行入口。
- 日历可以连续向下浏览月份，节日明显可区分，2027 年不会退化为只有三项中国节日。
