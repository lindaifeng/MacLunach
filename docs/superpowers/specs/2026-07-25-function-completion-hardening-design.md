# 一念功能完善与稳定性加固设计

## 背景与目标

本次修复处理功能审计中已经确认、且无需外部发布权限即可消除的问题：截图工具栏翻译入口未接通、截图 XPC 服务存在强制崩溃路径、统一权限中心覆盖不完整，以及标注编辑器暴露系统默认按钮样式。

目标是让这些入口具有一致、可恢复、可测试的行为；不接入应用内更新、Developer ID 签名、公证或正式发布流程。

## 范围

### 截图工具栏翻译

- `翻译` 是与 `文字识别` 不同的完成动作。
- 用户完成选区后，系统只捕获和识别一次，不创建 OCR 结果面板。
- 识别到的文字及语言提示直接交给既有 `TranslationPanelController`，由其展示并开始现有离线翻译流程。
- 取消、无文字、权限拒绝、识别失败或翻译不可用时，不展示空白翻译窗口，保持与现有工作台流程一致。

### ScreenshotService 存储根目录

- 服务初始化不得使用 `try!`。
- 无法创建 Application Support 目录时，服务记录可诊断日志，并使用受控的临时目录作为仅本次运行的降级根目录。
- 降级根目录只影响截图历史与项目文件的持久性，不得造成主应用或 XPC 服务崩溃；后续请求继续返回版本化错误或正常结果。

### 统一权限中心

- 在“设置 → 权限”中增加辅助功能状态，使用 `AXIsProcessTrusted()` 获取真实值，并提供系统设置恢复入口。
- 将登录项状态归入权限中心，显示 `SMAppService.mainApp.status` 的真实状态和系统恢复说明；通用设置不再重复提供独立开关。
- 完全磁盘访问没有可靠的公开 macOS 授权查询 API。页面必须明确显示“需在系统设置确认”，仅提供用途说明和跳转入口，不伪造“已授权”。

### 标注编辑器主题一致性

- 标注工具条和裁剪确认条不再使用 `.bordered`、`.borderedProminent` 或系统强调色。
- 改用现有主题令牌和项目交互样式，保留按下、禁用、键盘快捷键、帮助文本与辅助功能标识。

## 设计与数据流

```text
截图选区工具栏“翻译”
  → ScreenshotSelectionCompletionAction.translate
  → ScreenshotCoordinator 捕获 OCR 区域并识别一次
  → TextTranslationRequest
  → TranslationPanelController.show(request:)
```

翻译动作的识别结果不写入截图历史，也不触发 OCR 结果面板；翻译面板继续沿用既有的语言包检测、复制、取消与失败提示。

服务存储根目录通过可注入的路径解析器获得。生产解析器优先返回 Application Support 路径；失败时返回进程私有临时路径并记录降级原因。测试使用抛错解析器覆盖失败分支。

## 错误处理

- 翻译入口的错误复用工作台现有错误语义，不将识别失败伪装成翻译成功。
- 临时存储降级只在存储初始化失败时启用；不吞没后续捕获、编码、权限或 XPC 协议错误。
- 辅助功能、登录项和完全磁盘访问的状态均区分真实授权、需要用户在系统设置操作和无法公开确认三种情况。

## 测试与验收

- 工具栏映射测试：翻译动作映射为独立完成动作。
- 协调器测试：翻译动作只触发一次 OCR，并将 `TextTranslationRequest` 交给翻译展示回调。
- 存储根目录测试：Application Support 解析成功时使用持久路径；解析抛错时使用临时降级路径且可诊断。
- 主题回归：不允许标注工具条与裁剪确认条重新使用系统边框按钮样式。
- 运行 `swift test --package-path Packages/TouchKit`、相关 `TouchTests`、稳定签名 Debug 构建、`git diff --check`。截图/翻译真实操作需在已有屏幕录制权限和系统语言包条件下单独记录。

## 非目标

- 不引入网络翻译或第三方更新框架。
- 不写入 Apple ID、Team ID、Developer ID、描述文件或公证凭据。
- 不改变 Finder 剪切移动、截图滚动/GIF 的既有已验证行为。
