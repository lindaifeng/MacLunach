# 触达 macOS 桌面启动器 V1 设计规格

## 1. 文档信息

- 产品名称：触达
- 产品标语：心之所想，一触即达
- 统一部署基线：macOS 14.0 及以上，主程序、扩展、后台服务和全部功能插件不得使用不同的最低系统版本
- 分发方式：Developer ID 签名、公证后官网分发
- 默认启动快捷键：`Option + Space`
- 设计基线：用户确认的毛玻璃启动页原型
- 核心目标：让用户在不中断当前工作的情况下，快速完成应用启动、文件查找、截图处理和 Finder 文件操作。

## 2. 产品原则

1. 快。快捷键呼出后立即响应，索引、截图处理和 Finder 扩展不得阻塞启动器界面。
2. 安静。默认不抢占不必要的系统权限，不弹出无关窗口，不在操作完成后制造额外确认。
3. 可预测。相同快捷键、鼠标操作和上下文始终得到一致结果。
4. 渐进呈现。启动页只显示高频入口，复杂配置进入设置页，截图高级工具在需要时出现。
5. 本地优先。搜索索引、截图历史、快捷键和主题配置均保存在本机，不上传用户文件或截图。

## 3. V1 范围

V1 交付以下可独立验证的能力：

- 常驻菜单栏的启动器及全局快捷键。
- 应用搜索和启动。
- 基于本地索引的文件名搜索。
- 三个功能卡片：打开访达、截取屏幕、超级右键。
- 卡片排序、隐藏和快捷键自定义。
- 功能区统一管理，以及每个功能插件各自的设置页面。
- 三套毛玻璃主题。
- 区域、窗口、全屏和延时截图。
- 截图后浮动缩略图、标注、钉图、OCR、二维码识别和取色。
- Finder 右键扩展及核心文件动作。
- 权限、更新、快捷键、索引、截图、右键和外观设置。

V1 不包含：

- 第三方插件安装和插件市场。
- AI 功能。
- 云同步。
- 剪贴板历史管理器。
- 屏幕录制和 GIF 录制。
- 自动滚动长截图。
- 文档正文全文索引。

滚动截图、录屏和 GIF 进入 V1.1。V1 从第一天采用第一方功能插件架构，但只加载随应用签名和发布的内置插件；不开放第三方代码加载、插件安装或插件市场。功能区插件的版本化协议、隔离边界和未来市场演进见 `docs/superpowers/specs/2026-07-16-feature-plugin-architecture.md`。

## 4. 总体架构

采用原生插件化架构，SwiftUI 负责声明式界面，AppKit 负责窗口、焦点、菜单栏、全局快捷键和系统集成。启动器核心只管理窗口、搜索、功能区、主题、设置导航和插件生命周期，不包含任何具体功能实现。

```text
Touch.app
├── LauncherShell        启动器窗口、主题、键盘导航
├── FeatureRegistry      功能插件发现、校验、启停和排序
├── FeatureHost          功能卡片、动作路由和设置页托管
├── ApplicationSearch    应用发现、图标缓存、排序
├── FileIndex            初次扫描、SQLite 索引、FSEvents 更新
├── SearchCoordinator    合并查询、去重、排名
├── Settings             配置、权限和诊断
├── LoginHelper          登录启动和后台热键服务
├── FeaturePlugins
│   ├── FinderPlugin     打开访达
│   ├── ScreenshotPlugin 截图入口、设置和执行服务连接
│   └── SuperRightPlugin Finder 右键入口、设置和执行服务连接
├── XPCServices
│   ├── ScreenshotService 捕获、OCR、导出和历史处理
│   └── FileActionService 文件动作、冲突处理和撤销
└── FinderExtension      Finder 菜单和上下文传递
```

### 4.1 功能插件协议

每个功能按钮对应一个 `FeaturePlugin`，必须声明：

- 稳定且不可变的插件标识符。
- 名称、说明、图标资源和默认排序。
- 默认快捷键和可用快捷键范围。
- 卡片动作入口。
- 一个独立设置页面入口。
- 所需权限及权限状态提供器。
- 可选的独立执行服务。
- 数据架构版本和迁移器。
- 健康检查和恢复操作。

`FeatureRegistry` 只接受主应用签名中预先声明、通过完整性校验且部署目标为 macOS 14.0 的第一方插件。V1 不扫描外部目录、不执行下载代码，也不允许插件覆盖启动器核心设置。

第一方插件也必须遵循未来第三方插件所需的基本边界：拥有自己的配置、设置提供器、迁移和执行服务。宿主不得通过插件 ID 硬编码设置页面，也不得持有插件私有配置类型。未来第三方插件只使用声明式协议或独立签名进程，不向主应用或 Finder 扩展注入原生代码。

### 4.2 隔离边界

- 插件卡片和轻量设置界面通过协议由 `FeatureHost` 托管，不直接访问其他插件状态。
- 启动器进程只持有插件清单、卡片描述和设置描述；具体业务逻辑不得在卡片点击处理器中执行。
- 截图处理、OCR、图片导出和文件操作分别运行在独立 XPC 服务中。
- 插件只能通过受类型约束的请求模型调用自己的执行服务，不共享可变全局单例。
- 插件数据使用独立数据库或独立命名空间；迁移失败只停用对应插件。
- 插件设置由插件注册的提供器或声明式 schema 交给 `FeatureHost` 渲染，主应用不增加 `switch featureID` 特例。
- 文件、屏幕、剪贴板和外部应用等敏感能力通过宿主 capability broker 调用，插件未声明的能力不可访问。
- 插件崩溃、超时或权限失败时，`FeatureRegistry` 标记该插件不可用并提供重试，不关闭启动器。
- Finder 扩展只和 `FileActionService` 通信，不依赖截图插件或启动器窗口。
- 搜索是启动器核心能力，不作为可关闭插件；文件索引异常不得影响应用搜索。

插件生命周期统一为“未加载、可用、执行中、受限、故障、停用”。`FeatureRegistry` 是唯一状态来源：权限缺失进入“受限”，服务超时或迁移失败进入“故障”，用户关闭进入“停用”。插件不得自行修改其他插件状态。XPC 请求必须设置超时、支持取消并返回结构化错误。

### 4.3 系统版本一致性

- Xcode 工程、Swift Package、应用扩展、XPC 服务和测试目标统一设置 `MACOSX_DEPLOYMENT_TARGET = 14.0`。
- V1 插件清单不得声明高于或低于 14.0 的最低版本。
- 使用 macOS 15 或更高版本 API 时必须同时提供 macOS 14 回退实现；没有回退实现的 API 不得进入 V1。
- CI 在构建前检查所有 target 和 package 的部署版本，发现不一致立即失败。
- 发布测试至少覆盖 macOS 14 最新小版本、macOS 15 最新小版本和当前正式版 macOS。
- 所有架构目标同时构建和测试 `arm64` 与 `x86_64`；如果最终决定停止 Intel 支持，必须单独修改本规格和发布策略，不能由某个插件自行决定。

模块通过明确协议通信。索引、OCR、图片导出和文件操作在后台执行；界面状态只能在主线程更新。启动器面板、搜索索引和图标缓存均复用，不在每次呼出时重建。

## 5. 启动器界面

### 5.1 默认状态

- 左上角同一行显示“触达”和“心之所想，一触即达”。
- 右上角显示主题按钮和设置按钮。
- 搜索栏从左到右为：搜索图标、应用/文件分段按钮、`Tab 切换`提示、输入区域。
- 搜索栏下方居中显示三个紧凑横向卡片。
- 默认选中“应用”模式。
- 面板使用 `NSPanel`，显示在当前鼠标所在屏幕的可用区域中央。

### 5.2 呼出与关闭

- 默认 `Option + Space` 呼出或关闭。
- 快捷键可在设置中录入，保存前检查系统和触达内部冲突。
- 点击面板外、再次按启动快捷键或按 `Esc` 关闭。
- 有搜索内容时第一次 `Esc` 清空输入，第二次 `Esc` 关闭。
- 切换空间、显示器或全屏应用时，面板始终定位在当前交互屏幕。
- 关闭面板时恢复原应用焦点。

### 5.3 搜索状态

- 用户直接输入即可搜索当前模式。
- `Tab` 在应用和文件之间切换，并保留输入内容。
- 输入后，功能卡片以 120ms 淡出，结果列表在相同内容区出现。
- 清空输入后恢复功能卡片。
- `Up/Down` 移动选择，`Enter` 打开，`Command + Enter` 在 Finder 中显示，`Space` 调用 Quick Look。
- 搜索结果显示图标、名称、父路径或应用说明，并高亮匹配部分。
- 没有结果时展示可执行建议，例如切换搜索类型、检查索引范围或重建索引。

### 5.4 功能卡片

- 初始顺序：打开访达、截取屏幕、超级右键。
- 默认快捷键：`Command + 1`、`Command + 2`、`Command + 3`，仅在启动器可见时生效。
- 鼠标按下约 180ms 后进入排列状态；移动超过 4pt 时立即开始拖动，避免人为等待。
- 拖动时其他卡片使用弹簧动画让位，释放后保存顺序。
- 右键菜单提供：修改快捷键、隐藏功能、恢复默认。
- 快捷键冲突时不保存，并明确指出冲突对象。
- 隐藏卡片可在设置中恢复。
- 卡片的显示、排序、启停和快捷键由功能区统一管理，具体功能参数由对应插件自己的设置页管理。

## 6. 搜索设计

### 6.1 应用搜索

应用来源包括 `/Applications`、`/System/Applications`、`~/Applications` 和 Launch Services 已知应用。

索引字段：

- 显示名称。
- 本地化名称。
- Bundle Identifier。
- 应用路径。
- 图标缓存键。
- 最近启动时间。
- 用户启动次数。
- 名称拼音和拼音首字母。

排序顺序：完全匹配、前缀匹配、拼音匹配、模糊匹配，再叠加最近使用和使用频率。启动应用使用 `NSWorkspace` 异步 API。

### 6.2 文件索引

macOS 无法直接复用 Everything 读取 NTFS MFT 和 USN Journal 的机制。触达采用轻量文件名数据库：

1. 初次运行时扫描用户授权的根目录。
2. 读取文件名、标准化路径、类型、大小、创建时间和修改时间。
3. 批量写入 SQLite，查询表使用前缀和 trigram 索引支持部分匹配。
4. 使用 FSEvents 监听根目录变化并增量更新。
5. 使用 Spotlight 元数据查询补充系统标签、内容类型和 iCloud 条目。
6. 外置卷挂载后按用户设置选择扫描或忽略。

默认索引范围：桌面、文稿、下载、用户自选目录。默认排除缓存、废纸篓、系统目录和用户配置的排除规则。用户可以开启完整用户目录或外置磁盘索引；需要额外权限时按需引导，不在首次启动时集中索取。

### 6.3 索引生命周期

- 初次扫描在后台执行，已经写入的结果立即可搜。
- 设置页显示扫描目录、文件数量、数据库大小、最后更新时间和当前状态。
- FSEvents 事件中断、丢失或根目录身份变化时，对受影响目录执行局部重扫。
- 数据库损坏时自动隔离旧库并重建，不阻塞应用搜索。
- 目录被移除授权时删除对应索引记录。
- 搜索结果打开失败时从索引删除失效项，并提示文件已移动或删除。

## 7. 截图与钉图

### 7.1 捕获模式

- 区域截图。
- 窗口截图，支持保留或去除窗口阴影。
- 全屏截图。
- 多显示器截图。
- 3 秒、5 秒和 10 秒延时截图。
- OCR 区域识别。
- 屏幕取色。

捕获使用 ScreenCaptureKit。首次使用截图时才请求屏幕录制权限；被拒绝时展示权限说明和打开系统设置按钮，启动器其他功能继续可用。

### 7.2 区域选择体验

- 截图开始后隐藏触达自身窗口。
- 光标旁显示选区尺寸。
- 支持拖动八个控制点调整选区。
- 按住 `Space` 移动整个选区。
- 方向键微调 1px，按住 `Shift` 微调 10px。
- `Esc` 取消，`Enter` 完成。
- 鼠标移动到窗口上时提供窗口边界吸附。

### 7.3 捕获后工作流

截图完成后默认复制到剪贴板，并在屏幕右下角显示浮动缩略图。设置中可以改为仅保存、复制并保存、直接进入标注或不显示缩略图。

浮动缩略图操作：

- 单击：打开标注。
- 双击：钉图。
- `Command + C`：复制。
- 拖动：将图片拖到其他应用或 Finder。
- 右键：保存、另存为、OCR、钉图、删除。
- 超时：按设置自动隐藏，不删除截图历史。

### 7.4 标注工具

- 箭头、直线、矩形、圆形。
- 画笔、高亮。
- 文字、编号步骤。
- 马赛克、模糊。
- 放大镜。
- 裁剪。
- 撤销、重做。
- 颜色、粗细、字体和透明度。
- 圆角、阴影、边距和渐变背景美化。

标注采用非破坏性图层模型。保存前保留可编辑历史；导出时统一渲染。OCR、二维码识别和图片导出在后台执行。

### 7.5 钉图

- 钉图为无边框置顶面板，不进入 Dock。
- 支持拖动、缩放、透明度、折叠、复制和关闭。
- 支持鼠标穿透，并提供明显的恢复方式。
- 支持多张钉图和跨空间显示设置。
- 应用退出或系统重启后，按用户设置恢复上次钉图。
- 钉图文件存入应用支持目录，清理历史时提示是否同时删除钉图源文件。

### 7.6 截图历史

- 默认保留最近 30 天或最多 500 张，以先达到的条件为准。
- 支持按时间、尺寸和 OCR 文本搜索。
- 用户可关闭历史、修改保留规则或一键清空。
- 删除历史文件进入应用内部回收区，保留 24 小时后物理删除。

## 8. 超级右键

### 8.1 架构和安全边界

Finder 扩展只读取当前选择和提供菜单，不执行耗时文件操作。它通过 XPC 将标准化 URL、选择类型和动作标识发送给独立的 `FileActionService`。

首版动作分为：

- 只读动作：复制路径。
- 打开动作：打开终端。
- 可恢复动作：新建文件、新建文件夹和剪切移动。

首版没有永久删除、批量替换或静默覆盖等高风险动作。剪切移动必须经过冲突检查，跨卷校验成功前不得删除源文件。

### 8.2 上下文菜单

文件夹空白处或单个文件夹：

- 打开终端。
- 复制当前目录路径。
- 新建文件。
- 新建文件夹。
- 存在待移动项时动态显示“粘贴到此处”。

选中文件：

- 复制完整路径。
- 剪切。
- 打开终端，定位到文件父目录。

首版五个功能直接组成一段 Finder 原生菜单，不包进总子菜单。“新建文件”使用二级菜单展示已启用格式。多选时只展示支持批量处理的功能，不可用项直接隐藏。

### 8.3 剪切和移动

“剪切”使用触达移动剪贴板：

1. 保存待移动文件 URL、身份信息和时间。
2. 在源文件上展示待移动状态。
3. 用户在目标文件夹执行动态出现的“粘贴到此处”。
4. `FileActionService` 检查同名冲突、权限、磁盘空间和跨卷场景。
5. 同卷使用移动，跨卷使用复制后校验再删除源文件。
6. 完成后清除待移动状态并汇总结果。

发生冲突时提供跳过、保留两者和取消。首版不提供替换。

### 8.4 新建文件模板

首版内置 TXT、Markdown、RTF、JSON、XML、YAML、CSV、HTML、Swift 和 Python 十种常用格式。用户可以启用、停用和排序内置格式，也可以新增包含显示名称、扩展名、默认文件名与可选初始内容的自定义格式。新建时使用可预测的递增名称处理重名。

### 8.5 自定义

设置页允许：

- 开关和排序“新建文件、新建文件夹、剪切、复制路径、打开终端”五个功能。
- 选择默认终端。
- 管理内置与自定义文件格式，并预览“新建文件”子菜单。
- 恢复默认菜单。
- 查看扩展启用状态和诊断通信。
- 从启动器点击“超级右键”时直接进入本设置页。

## 9. 主题和动效

三套主题：

- 晶透毛玻璃，默认。
- 曜石深色玻璃。
- 暖色烟熏玻璃。

主题由统一设计令牌控制颜色、材质、边框、阴影和强调色，切换时使用 180ms 交叉淡化，不重建窗口。系统开启“减少动态效果”时关闭位移动画；开启“降低透明度”时使用高不透明背景并保持文字对比度。

交互动效：

- 面板显示：120ms 淡入加 0.98 到 1.0 缩放。
- 面板关闭：90ms 淡出。
- 搜索结果变化：80ms 交叉淡化，不逐项大幅移动。
- 卡片悬停：100ms 边框和背景变化，不使用持续发光。
- 拖动排序：弹簧阻尼动画，释放后不回弹过度。

## 10. 设置中心

设置页采用“系统设置 + 功能区 + 功能插件设置”三级结构：

```text
设置
├── 通用
├── 搜索与索引
├── 功能区
│   ├── 功能区总览
│   ├── 打开访达
```

### 10.1 系统级设置

1. 通用：开机启动、菜单栏、语言、启动器快捷键、默认呼出屏幕。
2. 搜索与索引：索引范围、排除规则、外置卷、状态和重建。
3. 外观：主题、动画、透明度、卡片尺寸。
4. 权限：按功能插件分组显示屏幕录制、Finder 扩展、文件目录和辅助功能状态。
5. 更新：自动检查、稳定或测试通道、版本记录。
6. 隐私与存储：各插件占用、数据库和截图占用、一键清理、数据导出。
7. 关于：版本、开源许可、反馈和诊断包导出。

### 10.2 功能区总览

功能区是所有功能按钮的统一管理入口，负责：

- 查看已集成的全部第一方功能插件。
- 启用或停用功能插件。
- 控制卡片是否显示在启动页。
- 拖动调整卡片排序。
- 统一修改卡片快捷键并检查冲突。
- 查看插件版本、权限、健康状态和存储占用。
- 进入具体功能插件的设置页。
- 重置单个插件，插件重置不得清除其他插件数据。

停用功能插件时，功能区必须说明会停止哪些后台服务、隐藏哪些入口以及是否保留数据。打开访达作为轻量基础插件允许隐藏，但不能从 V1 应用包中卸载。

### 10.3 具体功能插件设置

- 打开访达：默认打开位置、新建窗口或激活已有窗口、是否在当前 Space 打开。
- 截取屏幕：截图模式快捷键、保存位置、命名规则、捕获后动作、历史保留、标注默认值、OCR 和钉图行为。
- 超级右键：五个功能的开关与排序、内置及自定义文件格式、默认终端、Finder 扩展状态和剪切状态。

每个插件只能修改自己的配置。系统级启动器快捷键、主题、更新和全局索引不出现在插件设置中，避免重复入口和状态冲突。

权限中心显示“未请求、已授权、被拒绝、受限制”四种状态，并提供解释、重试和打开对应系统设置入口。没有某项权限时，只禁用依赖该权限的功能。

## 11. 数据存储

- `UserDefaults`：主题、界面行为和轻量开关。
- SQLite：应用索引、文件索引、使用排名和截图历史元数据。
- Application Support：截图、钉图源文件、模板和图标缓存。
- Keychain：未来可能需要的更新或网络凭据；V1 不保存账号密码。

每个功能插件使用独立目录 `Application Support/Touch/Features/<plugin-id>/` 和独立配置命名空间。插件不得直接读写其他插件目录；需要共享的数据由启动器核心通过只读值或受控服务提供。卸载、停用、重置和迁移都以插件标识符为边界。

所有数据库迁移必须有版本号和回滚策略。用户清理数据后，界面立即反映结果。诊断包默认移除完整文件路径，仅在用户明确勾选时包含路径信息。

## 12. 错误处理

- 全局快捷键冲突：保持旧快捷键并指出冲突组合。
- 索引不可用：应用搜索继续工作，文件页显示恢复操作。
- 文件无权限：提供授权目录或在 Finder 中显示，不循环弹窗。
- 截图权限缺失：展示单一权限引导，不影响其他功能。
- Finder 扩展未启用：超级右键卡片进入设置并显示启用步骤。
- 功能插件初始化失败：只停用失败插件，保留启动器、搜索和其他插件，并提供查看诊断和重新加载入口。
- XPC 服务无响应：取消当前任务、重启对应服务并保留可恢复数据；连续失败后自动隔离该插件。
- 插件数据迁移失败：保留旧数据备份，停用对应插件并提供恢复默认选项，不迁移其他插件数据。
- 插件系统版本不符合清单：构建和发布检查直接失败，不允许在用户设备上以缺少功能的状态运行。
- 文件移动冲突：暂停动作并等待用户选择，不静默覆盖。
- 外置磁盘移除：停止相关动作并保留可恢复状态。
- 更新失败：继续使用当前版本并保留清晰错误信息。

## 13. 性能验收

在 Apple Silicon、索引约 100 万文件的测试环境下：

- 常驻状态呼出面板 P95 小于 120ms。
- 搜索键入到首批结果显示 P95 小于 50ms。
- 空闲 CPU 平均低于 1%。
- 空闲内存目标低于 150MB。
- 初次索引不造成界面掉帧。
- 截图完成到缩略图出现 P95 小于 300ms。
- Finder 菜单构建 P95 小于 80ms。
- 动画在 60Hz 屏幕保持稳定，在高刷新率屏幕不人为限制到 60fps。

所有指标以发布构建测量，不使用 Debug 构建结果作为验收依据。

## 14. 可访问性和输入

- 所有按钮和卡片提供 VoiceOver 标签和操作说明。
- 全流程可只用键盘完成。
- 文字与背景达到可读对比度。
- 尊重系统减少动态效果、降低透明度和增大对比度设置。
- 快捷键录入支持不同键盘布局。
- 不以颜色作为唯一状态提示。
