# 一念超级右键剪切移动设计

日期：2026-07-25

## 目标

为 Finder“超级右键”补齐可恢复的剪切移动工作流。用户在来源文件或多选文件上执行“剪切”，再在单个目标文件夹或 Finder 空白目录执行“粘贴到此处”。功能必须不静默覆盖文件，跨卷复制校验成功前不得删除源文件。

## 范围

- 支持文件、文件夹及多选项的剪切和粘贴到目标目录。
- 同名冲突支持跳过、保留两者、取消；首版不支持替换。
- 支持同卷移动与跨卷复制后校验再删除。
- 支持来源失效、权限不足、空间不足、XPC 中断和用户取消的可诊断恢复。

不包含：永久删除、静默覆盖、与 macOS 通用剪贴板互操作、复杂的跨设备同步或撤销历史。

## 架构

```text
Finder Extension
  ├─ 剪切：捕获 Finder 上下文并写入原子 MoveClipboard
  └─ 粘贴：经原子 ActionRelay 请求主应用
       → FileActionService.xpc
       → MoveClipboardStore / MoveExecutor
       → 原子响应中继
       → Finder Extension
```

Finder Extension 仅捕获上下文、决定菜单可见性和写入/读取中继请求，不执行耗时文件移动。主应用沿用现有无激活后台中继。`FileActionService` 是唯一允许执行文件系统变更的进程，并保持现有版本化 XPC 信封和调用方签名校验。

## 持久化移动剪贴板

`MoveClipboard` 原子保存到现有 SuperRight ActionRelay 目录，字段包括：

- `version`：格式版本。
- `items`：每项包含标准化来源 URL、资源标识、文件名与是否目录。
- `createdAt` 与 `expiresAt`：用于失效判断和恢复提示。

写入采用临时文件后原子替换。粘贴前读取并校验格式、时间和来源资源标识，避免路径被同名新文件替换后发生误移动。仅在全部项成功时清空剪贴板；取消或局部失败保留未完成项，方便用户修复后重试。

## 菜单行为

- 选中文件或目录时显示“剪切”。
- 目标是单个目录或 Finder 空白目录且存在有效移动剪贴板时，动态显示“粘贴到此处”。
- 来源与目标相同、目标不可写、剪贴板过期或来源全部失效时，不显示粘贴入口或显示可诊断失败结果。
- 多选来源作为一个批次处理；目标只能是一个目录。

## 执行与恢复

1. 预检来源存在性、资源标识、来源/目标权限、目标目录、同名冲突和可用空间。
2. 同卷使用 `FileManager.moveItem`；跨卷先复制到目标临时位置。
3. 跨卷复制完成后，校验目录树或文件的大小与内容摘要；校验成功才删除源文件，再将临时目标原子改名为最终目标。
4. 冲突策略逐项执行：跳过保留来源；保留两者生成可预测的不重名名称；取消停止尚未处理项。
5. 跨卷复制/校验失败时清理临时目标，绝不删除源文件。已完成项在响应中明确列出。
6. 返回每项成功、跳过或失败原因的汇总结果；Finder 仅显示安全摘要，不将完整用户路径写入公开日志。

## 测试与验收

- `MoveClipboard` 的编码、版本拒绝、原子写入、过期和资源标识校验。
- 同卷移动、文件夹与多选、同名三策略、来源失效、目标不可写、取消及局部失败。
- 跨卷复制、校验失败不删源、临时文件清理。
- FileAction XPC 请求/响应版本兼容、调用方校验与超时/中断恢复。
- Finder 菜单在剪切来源、有效目标、无效目标与过期状态下的可见性。
- 真实 Finder 验收：剪切文件和目录、三种冲突策略、跨卷磁盘（如可用）及 XPC 重启后重试。
